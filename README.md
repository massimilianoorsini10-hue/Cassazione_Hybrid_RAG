# CassazioneHybridRAG
Un progetto di studio in corso per la raccolta, l'estrazione e l'analisi di dati testuali non strutturati provenienti dalle sentenze civili della Corte di Cassazione.

## Obiettivo del progetto
Sperimentare e prototipare una pipeline end-to-end per il trattamento di documenti giuridici, partendo dall'automazione del recupero dati fino alla preparazione dei testi per future applicazioni di Information Retrieval e RAG (Retrieval-Augmented Generation).

## Stato dei lavori (Componenti attivi)

* **[In corso] Web Scraping Automation (`/scraping`):** Script in Python basato su Selenium per l'interrogazione automatizzata dell'archivio delle sentenze civili e l'estrazione dei documenti di interesse.
* **[In arrivo] Data Cleaning & Parsing (`/preprocessing`):** Moduli per la pulizia del testo, la gestione dei margini e la normalizzazione strutturata dei PDF estratti.

## Stack Tecnologico
* **Linguaggio:** Python
