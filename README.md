# Cassazione_Hybrid_RAG
Progetto di studio per l'estrazione e l'analisi di sentenze civili della Corte di Cassazione. Sviluppo incrementale di una pipeline Python per automazione dati e pulizia testi, finalizzata alla prototipazione di sistemi di Information Retrieval. Include script di scraping con Selenium e moduli di preprocessing per documenti giuridici.
